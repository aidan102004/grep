# grepmini
 
A lightweight implementation of `grep` — a command-line utility for searching text patterns in files. Written in C++ with efficient string matching algorithms.
 
## Features
 
 
- Search for patterns (regex or literal strings) in files
- Inbuilt lightweight RegexEngine for pattern matching (`-E`)
- Limit matches (`-m`)
- Only matches (`-o`)
- Recursive searching (`-r`)
- Recursive directory search (`-r`)
- Count matches instead of printing them (`-c`)
- Display line numbers with matches (`-n`)
- Color output for matched patterns (`--color`)
- Support for multiple files
